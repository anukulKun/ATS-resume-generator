# Contributing

Thanks for helping improve ATS Resume Generator.

## Before You Open a Pull Request

Run:

```bash
npm run doctor
```

Also check that you did not include private job-search files:

- `cv.md`
- `config/profile.yml`
- `portals.yml`
- anything inside `data/`
- anything inside `reports/`
- anything inside `output/`

## What Good Contributions Look Like

- Clear setup instructions
- Safer defaults for privacy
- Bug fixes
- Better templates
- Simpler wording for non-technical users
- Small changes that are easy to review

## What To Avoid

- Adding personal data
- Adding one-person-specific career advice to shared files
- Creating a second workflow when an existing script or mode already does the job
- Making the beginner setup harder

Open an issue or pull request in this repository when you are ready.
