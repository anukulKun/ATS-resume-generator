# Project Docs

This folder holds project policy and maintainer documents.

| File | Purpose |
|------|---------|
| `CODE_OF_CONDUCT.md` | Community behavior rules |
| `CONTRIBUTING.md` | How to contribute |
| `DATA_CONTRACT.md` | Which files are private user data and which are shared system files |
| `LEGAL_DISCLAIMER.md` | Legal and acceptable-use notes |
| `SECURITY.md` | How to report security issues |

These files are not needed for first-time setup. New users should start with the root `README.md`.
