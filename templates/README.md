# Templates

These are starter files used by ATS Resume Generator.

Keep these files generic. Put your own details in:

- `cv.md`
- `config/profile.yml`
- `modes/_profile.md`
- `portals.yml`

## Files

| File | What it is for |
|------|----------------|
| `cv-template.html` | Layout used when ATS Resume Generator creates a PDF CV |
| `states.yml` | Allowed tracker statuses |

## How to use them

Copy `starter-kit/portals.example.yml` to `portals.yml` if you want ATS Resume Generator to scan company career pages.

Do not rename the states in `states.yml`. The tracker scripts expect those names.
